# Night Vision

A tiny night vision resource pack for [Polytone](https://modrinth.com/mod/polytone) or [OptiFine](https://optifine.net/home), implemented using custom lightmaps and environment attributes modifiers.

Custom lightmap support is currently not available in Polytone for Minecraft 1.21.10 and later, and the modified environment attribute only exists in Minecraft 26.1+, so you may only be able to use the resource pack with OptiFine on versions in between.

When using [OptiFine](https://optifine.net/home), requires: Custom Colors: ON, Smooth Lighting: OFF, Dynamic Lights: OFF

> **Remember to check server rules before using resource packs like this in multiplayer.**
